# Gabinete para Waveshare ESP32-S3 Touch LCD 7"

Gabinete imprimible en 3D para la pantalla **Waveshare ESP32-S3-Touch-LCD-7B** (1024x600).

## Compatibilidad

- **Waveshare ESP32-S3-Touch-LCD-7B** — pantalla táctil 7" capacitiva

## Archivos STL

| Archivo | Descripción |
|---------|-------------|
| `enclosure.stl` | Gabinete completo para la pantalla |

## Material de impresión

| Material | Recomendación |
|----------|---------------|
| **PLA** | Adecuado para uso interior |
| **PETG** | Mayor resistencia térmica |
| **ABS** | Más resistente pero requiere cámara cerrada |

**Color:** a elección; negro o gris dan un acabado profesional.

## Fuente original

Diseño disponible en Printables: [Waveshare ESP32-S3 7inch Capacitive Touch Display Enclosure](https://www.printables.com/model/1306944-waveshare-esp32-s3-7inch-capacitive-touch-display)

## Instalación

1. Imprime el gabinete con las configuraciones recomendadas del modelo
2. Inserta la pantalla Waveshare en el gabinete
3. Conecta el cable USB-C para alimentación
4. Opcionalmente, monta en pared o coloca sobre una superficie

## Notas

- El diseño permite acceso al puerto USB-C y ranura microSD
- Verifica las dimensiones antes de imprimir si tu pantalla tiene variantes
